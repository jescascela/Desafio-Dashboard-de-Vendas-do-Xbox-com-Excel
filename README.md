# 📊 Dashboard de Assinaturas - Excel

## 📌 Sobre o Projeto
Este projeto consiste na construção de um **Dashboard analítico em Microsoft Excel** para análise de assinaturas de um serviço de jogos.  
O objetivo é organizar dados de assinantes, realizar cálculos automáticos e apresentar **indicadores visuais que auxiliem na tomada de decisão**.

O projeto utiliza recursos nativos do Excel como:

- Fórmulas
- Tabelas estruturadas
- Tratamento de dados
- Indicadores
- Dashboard interativo

---

## 🎯 Objetivos

- Organizar uma base de dados de assinantes
- Realizar cálculos automáticos de valores de assinatura
- Analisar diferentes tipos de planos
- Visualizar métricas importantes em um **Dashboard visual**

---

## 📂 Estrutura do Arquivo

O arquivo Excel está dividido em três abas principais:

### 1️⃣ Bases
Contém a **base de dados principal do projeto**.

Cada registro representa um assinante e inclui informações como:

- **Subscriber ID** – Identificador do assinante
- **Name** – Nome do assinante
- **Plan** – Tipo de plano contratado
- **Start Date** – Data de início da assinatura
- **Auto Renewal** – Renovação automática
- **Subscription Price** – Valor da assinatura
- **Subscription Type** – Tipo de cobrança (mensal, trimestral, anual)

Também inclui informações adicionais como:

- EA Play Season Pass
- Minecraft Season Pass
- Valor de cupons aplicados
- Valor total da assinatura

Essa base é utilizada para alimentar os cálculos e o dashboard.

---

### 2️⃣ Cálculos
Esta aba é responsável pelo **processamento dos dados**.

Aqui são realizados:

- Cálculos de faturamento
- Consolidação de informações
- Preparação de métricas
- Estruturação dos dados para o dashboard

As fórmulas permitem transformar os dados brutos da aba **Bases** em informações analíticas.

---

### 3️⃣ Dashboard
Apresenta a **visualização dos principais indicadores** do projeto.

O painel foi desenvolvido para facilitar a interpretação dos dados através de:

- Gráficos
- Indicadores visuais
- Métricas consolidadas
- Comparações entre planos

O objetivo é permitir uma **análise rápida do desempenho das assinaturas**.

---

## 📈 Métricas Analisadas

Entre as métricas possíveis de análise estão:

- Ticket Médio
- Receita Total
- Receita gerada pelas assinaturas
- Receita gerada pelos planos
